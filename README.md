# My AI Engineering syllabus in Dart.  

I'm building this repo to upload some of my practice and learning on Machine Learning, Deep Learning and related topics. I chose Dart because it has a similar syntax to most of commonly used languages and because it helps me to implement some things from scratch better (and its the first language I used for work when I started in IT).

As a guide to build the implementations I find very useful the syllabus built in the site aiengineeringfromscratch.com (In Sources).

I plan to update this repository with more topics and experiments on other related subjects from the curriculum or from other sources as I continue to learn.
